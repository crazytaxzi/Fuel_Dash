OPTIONAL ELECTRIC APU DATA GUIDE
================================

APU data is recognized from worksheet content. The filename and worksheet name are ignored.

COMMON COLUMNS
--------------
Week End / Date
Driver Code / Driver ID / Employee Code
Driver Name / Driver
Unit / Unit Number / Tractor / Truck
Electric APU Hours / APU Runtime Hours / APU Hours
Engine Idle Hours / Tractor Idle Hours / Idle Hours
APU Use % / APU Usage % / APU Utilization %
Battery SOC / Battery Charge % / State of Charge
Faults / APU Faults / APU Alerts
Notes / Comments

Driver code is the strongest identity match. Driver name is used only when the code is unavailable and the normalized name is unambiguous.

The dashboard uses the latest row for each driver or unit identity and prioritizes:

1. Check equipment
2. Use APU more
3. Review idle
4. No recent use
5. Working well

No savings claim is calculated from APU hours alone. The APU section separates possible equipment or availability problems from avoidable engine idle.
