PDF TO XLSX CONVERSION GUIDE
============================

WHAT IT DOES
------------

The converter inspects selectable PDF text and identifies supported report structures from headings, columns, dates, percentages, totals, and row patterns. The uploaded filename is ignored.

HOW TO USE IT
-------------

1. Extract the full Fuel Dashboard package.
2. Start the local PDF conversion page.
3. Choose PDF files or drag them onto the page.
4. Allow multiple downloads when converting several reports.
5. Copy the converted workbooks into the dashboard data folder.
6. Launch or refresh the dashboard.

HOW IT WORKS
------------

PDF text is reconstructed from page coordinates. The converter scores the reconstructed content against supported table structures, normalizes recognized rows, and creates a workbook containing:

- Table 1: normalized dashboard data
- Extracted Text: reconstructed source text for troubleshooting

Output names are derived from the uploaded file only for convenience. They are not used to classify the report.

PRIVACY
-------

Conversion runs on the local dashboard server. Reports are not uploaded.

LIMITATIONS
-----------

- PDFs must contain selectable text. Scanned PDFs need OCR first.
- A redesigned table may require another structural rule.
- An ambiguous PDF is rejected instead of being forced into the wrong parser.
