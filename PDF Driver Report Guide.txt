XLSX / PDF BASIC REPORT GUIDE
=============================

The dashboard supports these four basic reports in either XLSX or PDF format:

- Driver Fuel Metrics
- Fuel Compliance Analysis
- Fuel Noncompliant Cost Analysis
- MPG by Driver

Files may be mixed. For example, Driver Fuel Metrics and MPG by Driver may be
PDF while the two analysis reports remain XLSX.

FILENAMES
---------

Use these exact base names:

Driver Fuel Metrics.xlsx / Driver Fuel Metrics.pdf
Fuel Compliance Analysis.xlsx / Fuel Compliance Analysis.pdf
Fuel Noncompliant Cost Analysis.xlsx / Fuel Noncompliant Cost Analysis.pdf
MPG by Driver.xlsx / MPG by Driver.pdf

Place the reports in the dashboard's data folder for automatic loading, or
choose the folder containing them from the connection screen.

PDF REQUIREMENTS
----------------

- PDFs must contain selectable text.
- Image-only/scanned PDFs must be OCR'd first.
- The parser recognizes the layout and labels used by the matching XLSX exports.
- Keep report titles, table headers, dates, percentages, and totals visible.

WHAT BASIC MODE PROVIDES
------------------------

- Weekly fuel compliance
- Driver dispatch MPG
- Driver idle percentage
- Driver out-of-route percentage
- Overall gallon and location noncompliant cost
- Available driver MPG history
- Driver follow-up notes and shift-transition export

The basic reports do not contain transaction-level fueling events or unit-level
cost rows. Use the legacy Detail workbook when those drilldowns are required.

SOURCE PRECEDENCE
-----------------

The dashboard needs one matching file for each of the four basic reports. When
both XLSX and PDF versions of the same report are present, XLSX is preferred.

LIMITATIONS
-----------

PDF text order is produced by the report generator. If a PDF redesign moves or
renames columns, its parser may need to be adjusted using a representative file.
